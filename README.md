# Abstract
This application seeks to provide a digital notebook creation solution for chemistry students. The interface through which users can interact is via a web page, which allows for users to log in or register a new account if they are not already logged in. These logins are tracked using session cookies to avoid frequent logins. After logging in, students would have the ability to access a web page where they can create, edit, save, and export lab notebook documents. Users also have a dedicated dashboard page where previously saved lab notebooks can be accessed. These saved notebooks as well as user login information are saved to a SQLite database.

# Problem Description
The application seeks to address some issues present in the current system of physical lab notebooks used by Chemistry students for completion of lab work. Currently, students have a dedicated lab notebook that they will use during the semester to write down all information relevant to their labs, such as a description of experiments performed and steps taken during the experiment. Students are also expected to include lab safety rules at the start of the notebook, in addition to other formatting like a table of contents and chemical index for each lab.

The first issue with physical notebooks is the potential for notebooks to be lost or damaged. Especially in a lab environment there is a possibility of accidents resulting in damage to notebooks. By having an online lab notebook the risk of lab notes being lost when personal items are damaged is negated, since all digital notebooks are saved to the application’s SQLite database. The same applies for losing lab notebooks, since digital lab notebooks can be accessed on any device via the web browser.

The other issue with physical lab notebooks is regarding handwritten notes. Many students prefer writing notes and completing assignments digitally as opposed to physical notes. This makes digital lab notebooks a good option for those students who would prefer to type assignments instead of handwriting them. Additionally, digital assignments are also much easier for professors to grade, since a number of students may not have excellent handwriting.

# Solution
In order to create a comprehensive solution that addresses current issues with lab notebooks I created a full stack application to facilitate creating and editing of lab notebooks over the web. The only hardware depended on during development is my own personal laptop, however hosting the project requires a dedicated server. All of the frontend and backend components of the application were created using the Nextjs framework, a full stack web development framework based on React. This allowed for creation of detailed and user friendly interfaces. To save edited notebooks I utilized a SQLite database to allow for a simplistic and lightweight database architecture that can be easily updated.

When accessing the application via the web, users first arrive at the home page, where they can sign in or register an account in order to start editing notebooks. Once users have logged in or if they are already logged in they can start editing by navigating to the editing page. After log in users are redirected to their dashboard page, where they can see their saved notebooks and create new notebooks. On the notebook editor page students can begin creating a new lab notebook using various standard formatting tools like headers, bolding, italicizing, and bulleted/numbered lists as well as word processing capabilities for spelling and grammar check. The notebook editing page also has access to some unique editing features like inserting preformatted sections and a drawing notepad. From the notebook editor page users can export notebooks as pdf files as well as save them for editing later.

During design and implementation there were a number of issues that occurred and addressed as necessary. One of the more challenging aspects of creating the application was implementing the custom features in the notebook editor. Specifically, the drawing notepad was challenging to implement while maintaining proper format within the text editor. To best address this I implemented the drawing notepad as a node which opens a model for drawing with canvas js. The other major issue encountered during development was in database design. Initially I was using Prisma as the database ORM for the project, however during development I found that Prisma does not function as expected with my version of Nextjs. For remediating this I switched to using Drizzle as my ORM, which allowed me to perform database actions with typescript functions and internal API calls.
